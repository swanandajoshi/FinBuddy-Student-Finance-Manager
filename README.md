## Viva prep
- Why Bootstrap? Responsive grid, ready components, faster development.
- Grid breakpoints? sm 576, md 768, lg 992, xl 1200.
- How is the mobile menu built without JS? Hidden checkbox + CSS sibling selector (:checked ~).
- Wireframe vs prototype? Wireframe = layout skeleton; prototype = clickable interactive flow.
